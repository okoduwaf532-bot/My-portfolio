# Favour.dev portfolio

A responsive, single-page portfolio website built with plain HTML, CSS and JavaScript.

## Preview locally
1. Extract this folder.
2. Open `index.html` in a browser, or open the folder in VS Code and use the Live Server extension.
3. Update the contact and profile links before publishing.

## Personalise before publishing
- In `index.html`, replace `YOUR_EMAIL@example.com` with your email address.
- Replace the generic GitHub and LinkedIn links with your profiles.
- Add a real PDF CV at `assets/cv.pdf`. The current download button points to this location.
- The movie project currently uses `assets/movieflix-preview.png`, supplied as a Movieflix.nl screenshot.
- Replace the to-do project mockup with a real screenshot when one is available.
- Add each project's GitHub/demo URL only after verifying it.
- Only list technologies you can comfortably discuss in an interview.

## Publish for free
For a simple static website, you can publish this project with GitHub Pages:
1. Create a public GitHub repository, e.g. `favour-dev-portfolio`.
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub will show your public website URL when deployment finishes.

The `FAVOUR.DEV` text is branding only; a custom `.dev` domain is optional and would need to be purchased separately.
